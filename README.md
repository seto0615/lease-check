# Lease Check — 新リース会計のリース判定

[![公開ページ](https://img.shields.io/badge/公開-seto0615.github.io%2Flease--check-0A2846)](https://seto0615.github.io/lease-check/)
[![研修](https://img.shields.io/badge/IFRS_×_AI_勉強会-新リース会計-0A2846)](#)

新リース会計基準（企業会計基準第34号・適用指針第33号）のリース判定を、質問に答えながらたどれる研修用 Web アプリです。
研修資料「AI 活用研修 — 新リース会計のリース判定を Claude で行う」の演習データ（株式会社サンプル商事・6契約）と連動しています。

## 機能

| タブ | 内容 |
|---|---|
| 判定 | 借手／貸手／中間貸手（サブリース）／セール＆リースバックの判定フロー。「不明・要確認」は確認事項に集約 |
| 演習 | 6契約のクイズ。回答後に研修資料の解説と、辞書 Project への質問文を表示 |
| 仕訳計算 | 月額・期間・割引率からリース負債・使用権資産・毎月の仕訳・償却表を計算。月次 CSV を Excel で検算 |
| プロンプト | 4要素（目的・前提・出力の形・判断の基準）で判定プロンプト v2 を生成。Claude で直接開ける |
| 基準メモ | 判定の骨格、日本基準と IFRS 16 の主な違い、裏取りの習慣、入力してよい情報 |

## 使い方

- ブラウザで [公開ページ](https://seto0615.github.io/lease-check/) を開くだけ。スマホはホーム画面に追加するとアプリとして使えます
- データ（演習の回答・入力値）は端末の localStorage にのみ保存され、外部に送信しません
- 「Claude で開く」は claude.ai の新規チャットにプロンプトを渡すリンクです

> [!NOTE]
> 研修用の学習ツールであり、会計処理の最終判断を代替するものではありません。判定の根拠は基準・適用指針の原文で、金額は Excel で、事実は契約書で確かめてください。項番号はあえて載せていません。

## 構成

ビルド不要の静的サイト（GitHub Pages）。`index.html` ＋ `js/app.js`（画面）・`js/data.js`（判定フロー・演習データ）・`js/calc.js`（現在価値・償却表）。
